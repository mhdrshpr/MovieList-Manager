# راهنمای ساخت و اجرای برنامه دسکتاپ Movie List با Tauri

این پوشه حاوی کلیه فایل‌ها، کدها و پیکربندی‌های لازم برای تولید نسخه دسکتاپ ویندوز (`.exe`) سامانه **Movie List** با استفاده از فریم‌ورک سبک و پرسرعت **Tauri v2** است.

---

## 🌟 ویژگی‌های نسخه دسکتاپ
1. **حجم بسیار کم و سرعت بالا:** بهره‌گیری از موتور بومی ویندوز (Microsoft Edge WebView2) بدون تحمیل رم و پردازش اضافی فریم‌ورک‌های سنگین.
2. **پشتیبانی از System Tray (کنار ساعت ویندوز):**
   - با زدن دکمه ضربدر پنجره، برنامه کاملاً بسته نمی‌شود بلکه به System Tray می‌رود.
   - با کلیک چپ روی آیکون برنامه کنار ساعت، پنجره باز یا پنهان می‌شود.
   - با کلیک راست روی آیکون منوی اختصاصی شامل **«نمایش برنامه»** و **«خروج کامل»** در دسترس است.
3. **پنجره استاندارد و تم تیره:** اندازه پایه `1280x800`، با قابلیت تغییر اندازه (Resize)، تمام‌صفحه و هدر بومی ویندوز.
4. **قابلیت آفلاین و کش PWA:** تمامی کش‌های آفلاین سرویس‌ورکر و پایگاه‌داده محلی برنامه در حالت آفلاین در این پوسته دسکتاپ حفظ و بارگذاری می‌شوند.

---

## 🚀 روش‌های دریافت و بیلد فایل نهایی EXE

### روش ۱: بیلد ابری خودکار با GitHub Actions (ساده‌ترین روش - بدون نیاز به نصب هیچ ابزاری)
گردش‌کار خودکار در مسیر `.github/workflows/build-exe.yml` قرار داده شده است.
1. پروژه را روی مخزن گیت‌هاب پوش (Push) کنید.
2. در گیت‌هاب به سربرگ **Actions** بروید.
3. ورک‌فلو **Build Windows EXE (Tauri)** را انتخاب کرده و دکمه **Run workflow** را بزنید.
4. پس از اتمام (حدود ۳ الی ۵ دقیقه)، فایل نهایی نصبی و پرتابل `.exe` را از بخش **Artifacts** به صورت مستقیم دانلود کنید!
*(همچنین با انتشار هر Release یا Tag مانند `v1.0.0`، فایل نصبی به طور خودکار به بخش Releases اضافه می‌شود).*

---

### روش ۲: بیلد لوکال روی ویندوز
در صورتی که قصد دارید برنامه را روی سیستم خودتان کامپایل کنید:
1. ابزار **Rust** را از [rustup.rs](https://rustup.rs) نصب کنید.
2. فایل `build.bat` موجود در همین پوشه را اجرا نمایید.
3. اسکریپت به صورت خودکار `tauri-cli` را نصب کرده و فایل exe را در مسیر زیر تحویل می‌دهد:
   `exe file\src-tauri\target\release\bundle\`

## 📁 ساختار فایل‌های این پوشه
```
exe file/
├── README.md               # راهنمای حاضر
├── build.bat               # اسکریپت اجرای خودکار بیلد در ویندوز
├── ui/
│   └── index.html          # صفحه فال‌بک آفلاین و اتصال اولیه
└── src-tauri/
    ├── Cargo.toml          # مشخصات پروژه Rust و پکیج‌های Tauri
    ├── build.rs            # اسکریپت بیلد کامپایلر Rust
    ├── tauri.conf.json     # تنظیمات پنجره، تری، ابعاد، شناسه و آیکون‌ها
    ├── icons/              # آیکون‌های استاندارد ویندوز و System Tray
    └── src/
        └── main.rs         # کدهای اصلی Rust (مدیریت پنجره و System Tray)
```
